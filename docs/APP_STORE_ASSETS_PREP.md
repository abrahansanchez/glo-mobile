# Glō Mobile Branding & Store Assets Prep

This repo is now configured to read branding assets from the new structure:

- `assets/branding/`
- `assets/icons/`
- `assets/splash/`
- `assets/animations/`

## Expo-configured build assets

These files are active in `app.json`:

- App icon: `assets/icons/app_icon.png`
- Splash image: `assets/splash/splash_universal.png`
- Web favicon: `assets/branding/glo_favicon.png`

## Upload targets

Place these files in the folders below:

### Branding (`assets/branding/`)
- `glo_logo.png`
- `glo_logo_vector.svg`
- `glo_website_logo.png`
- `glo_social_icon.png`
- `glo_favicon.png`

### Icons (`assets/icons/`)
- `app_icon.png`

### Splash (`assets/splash/`)
- `splash_universal.png`
- `splash_iphone.png`
- `splash_android.png`
- `splash_tablet.png`

### Animations (`assets/animations/`)
- `splash_animation_reference.gif`

## App Store build note

- iOS and Android production icons/splash are generated by Expo during build from the configured files.
- If you replace configured files, run a fresh export/build to verify generated assets.
